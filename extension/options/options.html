The kinds of data the mapping agent looks for in a CRM, whatever the vendor. Each kind found is mapped once, captured straight away during that first mapping, and saved to its own daily file (…_users_…, …_customers_…, …_deals_……), next to …_messages_… (texts, emails, calls, notes) and …_reference_… (every lead source, status, role, salesperson… the CRM uses). A CRM keeps the kinds it was mapped for; change this and map it again to switch.
